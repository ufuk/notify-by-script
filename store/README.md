## 2. Permissions Justifications (Form Girdileri)

> Copy-paste these exact values into the Chrome Developer Dashboard privacy tab:

| Field in Dashboard            | Permission Name             | Justification (Paste this)                                                                                                                          |
|-------------------------------|-----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| **alarms gerekçesi**          | `alarms`                    | `To schedule notifications periodically based on user settings.`                                                                                    |
| **notifications gerekçesi**   | `notifications`             | `To display custom notifications generated by user scripts.`                                                                                        |
| **storage gerekçesi**         | `storage`                   | `To store user-provided content (script, interval, and activation state).`                                                                          |
| **offscreen gerekçesi**       | `offscreen`                 | `Evaluation of the script provided by the user itself, using sandbox.`                                                                              |
| **Ana makine izni gerekçesi** | `http://*/*`, `https://*/*` | `To be able to perform script evaluation which consists of HTTP/HTTPS requests (such as website health checks or API queries) defined by the user.` |

### Remote Code (Uzak Kod) Declaration

- **Uzak kod kullanıyor musunuz?**  
  `Hayır, uzak kod iznini kullanmıyorum.`  
  _(All scripts run locally within an isolated sandboxed iframe adhering to Chrome MV3 CSP regulations)._
